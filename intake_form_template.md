# nTrust.ai Feature Request Intake Form (FRTS v1.0)

Thank you for helping nTrust.ai improve. Submissions are tracked under the Feature
Request Tracking System (FRTS) with SLA first-response <= 24h.

## Mandatory fields
- **Title** (short, problem-focused)
- **Description** (what + why)
- **Product** (dropdown: PrivacyGuard Suite / TrustAudit Engine / nTrust Shield /
  nTrust.ai Website / Spine Engine OSS / nTrust Core Platform / TrustGuard /
  Enterprise Security Audit Service / nTrust.ai Web Dashboard MVP / General)
- **Requested priority**: P1 (critical) / P2 (high) / P3 (normal) / P4 (low)
- **Business value / expected impact**
- **Contact email**

## Optional fields
- Desired behavior / acceptance criteria
- Timeline constraints
- Compliance classification (NIST AI RMF category, EU AI Act risk class) — for
  GovernanceOfficer triage use; end users may leave blank.

## After submission
- Auto-reply with tracking id `FR-{PROD-ID}-{seq}`.
- Product Owner triage within 24h; roadmap decision communicated.
- Every state change is audit-logged (EU AI Act traceability).
